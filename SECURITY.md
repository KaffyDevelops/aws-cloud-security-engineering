# Security Policy

This repository is a public cloud-security portfolio project.

## Never commit

- AWS access keys or secret keys
- session tokens
- Terraform state
- real account identifiers if they are not required for public evidence
- private IP inventories tied to a real organisation
- production logs
- unredacted personal data

## Reporting a repository security issue

If you identify a secret, unsafe configuration or disclosure risk, do not publish the sensitive value in a public issue. Contact the repository owner through the professional contact route at https://kaffy.thecloudforge.app.
